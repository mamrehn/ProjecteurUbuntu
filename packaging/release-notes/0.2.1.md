## What's new in 0.2.1

A maintenance release: fixes from a review of the whole code base, and a lighter footprint. The settings and the way you
use the remote stay the same.

### Fixed

- **USB receiver:** the remote's buttons keep their functions after it reconnects (after a long pause or out of range).
  Before, holding a button or the double click could stop working until the receiver was plugged in again.
- **No more runaway fast forward:** a button that is held while the remote loses its connection is released. Before, a
  held "fast forward" could keep stepping through the slides.
- **One slide per press:** Next and Back move exactly one slide even when the remote's keys cannot be captured (for
  example while another program holds them). Before, every press moved two slides.
- **Vibration patterns keep their meaning:** a remote that wakes up slowly no longer buzzes a pulse twice, so a two-pulse
  alert can no longer feel like the three pulses of "time is up".
- **Your settings from the first second:** at login, and after the background service restarts, the remote waits for your
  settings before it vibrates. With vibration at 0 % it stays silent, and with the battery warning off it does not warn.
- **Timer:** an alert added during a talk (for example by an application's own profile) is not announced when its moment
  has already passed.
- **Profiles:** switching to an application whose profile holds Next for something else stops a running fast forward.
- **Settings window:** application names with "&" or "<" are shown correctly, and a profile can no longer store a
  keyboard shortcut that the background service would refuse.
- **Reconnecting:** after a connection error the remote is picked up again without restarting the service.
- `./setup.sh --deb FILE` accepts a relative path.

### Lighter

- The background service no longer looks for the remote every two seconds: the system tells it when a device appears,
  and it sleeps in between.
- Moving an effect takes about half the processor time in the service, and GNOME Shell only updates what moved.
- The presentation timer wakes once a second instead of four times.
- The service is built with Ubuntu's standard hardening flags and runs with a system call filter; the program is 9 %
  smaller.

### Upgrading

Install the new package as below, then **log out and in once**, so that both the background service and GNOME Shell use
the new version. The remote gives its long "connected" pulse when the service starts.
